# 💰 Expense Tracker - Django

A simple and clean Expense Tracker built with Django. Track your daily income and expenses easily.

## ✨ Features
- User Registration & Login
- Add, Edit, Delete Expenses
- Category wise Expense Tracking
- Dashboard with total balance

## 🚀 How to Run This Project

1. Clone the repo:
   git clone https://github.com/karpagamari22/Expense-Tracker.git

2. Install Django:
   pip install django

3. Run Migrations:
   python manage.py migrate

4. Start Server:
   python manage.py runserver

## 🛠️ Tech Stack
- Python
- Django
- HTML, CSS
- SQLite
